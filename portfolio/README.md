# Portfolio – Somkiat Nontamat

เว็บ static ล้วน (HTML/CSS/JS) ธีมส้ม-ดำ

## Deploy บน GitHub Pages
1. สร้าง repo ใหม่บน GitHub แล้ว push ไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป
2. ไปที่ Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save
3. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<username>.github.io/<repo>/`
